# dsh-studio（Harness Studio）

DeepSeek Harness 的「工作台」插件：在左侧栏新增一个入口——中文显示**工作台**，英文显示**Harness Studio**——中栏打开同名页面。

页面提供三件事：

1. 按两类展示技能：**全局技能**与**用户技能**；
2. 一个**价格时段提示开关**：打开后在左侧栏左下角（账号上方）用两种颜色标出 DeepSeek 当前处于**高峰期**还是**空闲期**；
3. 一个**账户余额开关**：打开后在同一位置显示当前 DeepSeek 账户的剩余余额。

## 页面结构

工作台分为三个视图，用页面顶部的页签切换（依次为「概览」「个性化界面」「技能」）；三个视图共用同一套刻线、字号与状态色语汇：

- **概览**（默认）：顶部是一把 24 小时价格刻度尺——标出北京时间 09:00–12:00 与 14:00–18:00 两个高峰区间、当前时刻光标，以及「北京时间的现在时刻 + 距下次切换」的倒计时；周末或法定节假日时高峰区间与图例都变为空心灰带，并注明当天全天空闲。刻度尺下方是三张读数卡，每张卡片只保留简要功能介绍与当前状态：技能（总数、全局/用户占比条）、账户余额（金额）、左下角提示（两个开关）。
- **个性化界面**：两块单列面板。
  - 「左下角状态提示」：价格时段提示、账户余额两个开关；打开余额后，还会出现自动更新间隔与「刷新余额」、余额读取状态。
  - 「主题」：内置浅色皮肤「浅海晨汐」——浅海底色、青绿强调色、侧栏海底等深线；选择「默认」即可回到 DSH 当前主题。
- **技能**：一块单列面板，标题「技能清单」+ 更具体的说明（来源、只读内容、展开与查看方式）；内容为搜索框，以及「全局技能」「用户技能」两个**可展开/收起**的分组，默认都收起。展开分组后先只显示技能名称，点某个名称才展开该技能的详情。

结构与样式都按可扩展方式组织：视图、概览卡片都是数据驱动的列表（`VIEWS`、`stats`），新增视图只需往 `VIEWS` 追加条目；颜色、间距与圆角统一由 `.dsws-page` 上的 CSS 变量和各主题 token 控制。

## 使用

### 技能

1. 在左侧栏点击「工作台 / Harness Studio」（位于「插件」与「计划任务」之间），切到「技能」页签。
2. 「技能清单」里有两个默认收起的可展开分组：
   - **全局技能**：由 DSH 宿主级插件注册的技能；当前这个 profile 里通常是 `office`、`office-docx`、`office-pptx`、`office-xlsx`（内置 Office 技能）与 `diagnose-windows-sandbox-acl`（Windows 沙箱诊断技能）。
   - **用户技能**：用户级技能目录里发现的技能，当前是 `~/.dsh/skills` 与 `~/.agents/skills`（例如 `alibaba-java-coding-guidelines`、`frontend-design`、`impeccable`）。
3. 点击分组标题展开/收起；展开后每个技能**只显示名称**，点名称才展开详情：模型/用户调用方式徽标、描述、`适用场景`、`SKILL.md` 绝对路径。
4. 搜索框同时筛选两类列表（按名称、描述、适用场景，本地完成），输入时两个分组会自动展开；各分组数量在筛选时显示「筛选中 N / 共 M 个」。
5. 右上角刷新按钮重新读取；读取期间图标旋转。失败时保留已加载列表并给出可重试提示（认证失败时改为「重新加载页面」）。
6. 安装或停用插件、连接重置后会自动重新读取。

### 个性化界面（价格时段 / 账户余额 / 主题）

两个状态开关位于「个性化界面」页签的「左下角状态提示」里，各自控制一行标记，位置都在左侧栏左下角、**账号（设置）入口上方**：

| 开关 | 显示 |
| --- | --- |
| 显示价格时段提示 | **高峰期**：琥珀色圆点（`--dsw-alias-state-warn-primary`）；**空闲期**：绿色圆点（`--dsw-alias-state-success-primary`）；文字保持主文字色以保证对比度。悬停可看当前时段、预计切换时刻与完整规则。 |
| 显示账户余额 | 品牌蓝色圆点（`--dsw-alias-brand-primary`）+ 当前余额；不可用时圆点退到次级色。悬停可看余额、更新时间与错误原因。 |

- 侧栏展开时显示色点 + 文案；收起为图标栏时只显示色点（悬停提示与读屏文本保留完整信息）。
- 价格时段每 30 秒重算一次，跨过边界自动切换。
- 两个开关状态保存在 Host 侧 `$DSH_HOME/dsh-studio/settings.json`，刷新页面或重启 DSH 后保留。

#### 价格规则与数据来源

按 [DeepSeek 官方价格页](https://api-docs.deepseek.com/quick_start/pricing)（核对于 2026-11-20）：

- **高峰时段**：UTC 周一至周五 01:00–04:00、06:00–10:00（北京时间 09:00–12:00、14:00–18:00），且当天不是中国法定节假日；按标准价计价。
- **空闲时段**：其余全部时间（含周末与法定节假日全天），价格是高峰价的 50%。

节假日表内置了国务院办公厅公布的 **2026、2027 年**法定节假日（含调休放假日期），见 `client.js` 里的 `HOLIDAY_RANGES`；表未覆盖的年份按「周一至周五的工作时段」计算，节假日当天会按高峰显示，需要时补充日期即可。

#### 余额来源与显示口径

- 通过 DSH 账户自身的 Remote（`ctx.remote.account.getBalance`）读取，插件**不接触任何密钥**；未登录或账户接口不可用时，标记显示「暂不可用」，页面里给出错误原因。
- 余额 = **充值余额 + 赠送余额**，按币种合计；格式与「设置 → 账户」一致：两位小数、千分位、正数截断到分、不足一分显示 `<¥0.01`、负数最小 0.01。
- 只在开关打开、页面打开、手动点「刷新余额」、连接重置或**自动更新到点**时读取；余额只留在内存，不写入设置文件。
- **自动更新**：余额开关下方有下拉选项「关闭 / 10 秒 / 30 秒 / 1 分钟 / 5 分钟」，默认关闭。选择后会按该间隔自动刷新余额；窗口隐藏时跳过刷新。10 秒间隔会对账户接口产生较频繁的请求，按需选择。
- 余额列表多币种时用 ` / ` 分隔。

### 主题

「个性化界面」页签的「主题」面板可以选择内置皮肤：

- **默认（跟随 DSH）**：使用 DSH 当前主题。
- **浅海晨汐**：纸白阅读区（`#FAFCFB`）搭配墨蓝正文（`#19323D`）、蓝灰辅助文字（`#506776`）和雾蓝灰代码块（`#EEF4F5`）。浅海青侧栏（`#E4F2F1`）用海玻璃青（`#CBE6E3`）标记当前会话。底部使用从预览图描出的透明 SVG，分别保留浅水底色、深浅不一的青绿等深线和局部亮边，靠近会话列表逐渐淡出。当前标签与发送按钮使用深青（`#006F78`）。

它是「token 覆盖 + 侧栏海底等深线」的皮肤层，不是注册到 DSH 主题列表里的官方主题；DSH 升级若改动 token 名称，可能只生效一部分（不会报错）。

## 数据来源与范围（技能）

读取走本插件 Host 半部的只读端点 `GET /dsh-studio/skills`，返回 `{ global, user, complete }`：

- `global`：`skills.snapshot({})` —— Host 全局技能层，不传会话、不传工作目录。
- `user`：临时取**默认预设**的只读作用域（`agentPresets.acquireScope()`）读取合并目录，只保留 `source` 为 `user-dsh` / `user-agents` 的条目，也就是用户级技能目录；读取完立即释放作用域。

因此列表**不随会话变化**，也**不包含**：

- 项目技能（`<cwd>/.dsh/skills`、`<cwd>/.agents/skills`，取决于会话工作目录）；
- 预设私有技能（例如预设通过 `customSkillDirs` 挂载的 `dsh-doc`，`source` 为 `custom`）。

## 安全边界

端点沿用 DSH 连接层的准入规则（`connection.requestRejection`），只接受**同源**、且携带 DSH 已认证浏览器会话（`HttpOnly; SameSite=Strict` Cookie）的请求：

| 端点 | 方法 | 说明 |
| --- | --- | --- |
| `/dsh-studio/skills` | `GET`、`HEAD` | 返回两类技能；其他方法 405 |
| `/dsh-studio/settings` | `GET`、`HEAD`、`PUT` | 读取/局部更新设置；`PUT` 只接受已知设置：`pricingIndicator`、`balanceIndicator`（布尔）、`balanceRefreshMs`（`0`/`10000`/`30000`/`60000`/`300000`）与 `themeSkin`（`default`/`sea`），请求体上限 4 KiB |
| `/dsh-studio/diagnostic` | `POST` | 仅用于排障：Client 半部把渲染错误写入 `$DSH_HOME/dsh-studio/diagnostics.log`，请求体上限 16 KiB |

未认证返回 401/403，服务缺失返回 503。技能与设置都只在本机读写，不发送任何数据到外部，不新增模型请求，不写入会话日志。

## 排障

- 页面或左下角标记渲染出错时会显示「工作台渲染出错：…」而不是整块白屏，同时把错误（含堆栈）追加到 `$DSH_HOME/dsh-studio/diagnostics.log`。
- 该日志只在本机、只在出错时写入；用于定位问题，可随时删除。

## 限制与更新

- 页面是全局面板，不绑定会话，也不显示会话信息。
- 技能正文（内容）不在页面上加载，只显示技能元数据；加载正文请使用输入框的 `/` 菜单或 `skill` 工具。
- 价格时段的判定只用浏览器本机时钟；设备时间不准时标记也会跟着偏。
- 余额读取依赖 DeepSeek 账户功能；未登录、账户不可用或无账户控制器的部署只显示「暂不可用」。
- 「浅海晨汐」是浅色皮肤，覆盖的是颜色 token 与侧栏背景；在深色主题下会被强制成浅色，属于预期行为。
- 端点由 Host 半部提供。**刚更新插件代码后**：
  - 只改了浏览器半部（`client.js`）：刷新页面即可；
  - 改了 Host 半部（`index.js`）：在插件管理里重新应用该插件；若提示需要重启，则重启一次 DSH。
- 安装/停用插件后技能列表会自动刷新；直接增删用户技能目录中的文件不会实时推送，点刷新按钮即可。

## 从旧名称迁移

本插件原名 `dsh-workstation`。在**设置 → 插件**中移除 `dsh-workstation`（或先停用），再安装本包即可；两者的面板 id 不同（`studio`），旧入口会随旧包消失。

## 停用与移除

- 停用：**设置 → 插件** 中关闭 `dsh-studio`；入口、页面、左下角标记与两个端点一并消失。
- 移除：在**插件**页面对 `dsh-studio` 执行移除。设置文件 `$DSH_HOME/dsh-studio/settings.json` 不会被自动删除，可手动清理。

## 包结构

| 文件 | 作用 |
| --- | --- |
| `index.js` | Host 半部：技能端点、设置读写端点 |
| `client.js` | 浏览器半部：左侧栏入口、工作台页面、左下角状态提示（价格时段与账户余额） |
| `cordis.patch.yml` | bundle 载入的 Loader 行 |
| `locale/en.json`、`locale/zh.json` | 插件管理页的标题与描述（英文 Harness Studio / 中文 工作台） |
| `icon.svg` | 插件图标（24×24，侧边栏使用同一几何） |
